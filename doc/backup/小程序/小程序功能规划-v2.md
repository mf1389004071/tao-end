# 10倍好智慧成长小程序功能规划 v2

> 基于《260129-业务架构需求说明书》与 `changelog-2-business.xml` 表设计对齐后的规划版本。

## 一、文档与数据依据

- **业务架构**：`260129-业务架构需求说明书.md`（愿景/使命/目标、战略能力、价值主张、关键活动、客户细分、微信小程序要求等）
- **表结构**：`tao-end/geek-admin/.../changelog-2-business.xml`（event_info / event_join / event_session、knowledge_category / knowledge_content / knowledge_comment / knowledge_action、user_point_logs / user_contrib_logs / user_invite / user_growth、notices / notifications、user_profiles、identities、point_product / point_redemption 等）
- **原型参考**：`界面原型.html`（发现/成长/连接/消息/我的、课程与话题详情、工具详情、公告、邀请、成长地图、积分明细、搜索、发布心得）

## 二、产品定位与原则（不变）

1. **产品定位**：基于「个人产品化」与道家智慧，通过**成长导航、知识共生、价值连接**，助力用户生命绽放的智慧成长平台。
2. **设计原则**：溪水模型（感知-浸润-融入-奔涌）、价值观显性化（成为管道、极致利他）、业务闭环优先、MVP 按期推进（见需求优先级与期数规则）。

## 三、小程序与业务架构/表结构映射

| 业务架构/表 | 小程序能力 | 说明 |
|------------|------------|------|
| **用户信息 / sys_user + user_profiles** | 登录、个人资料、身份与成长阶段展示 | 唯一ID、身份标签、贡献点/积分/成长日、成长阶段 |
| **身份 / identities** | 身份标识、权益说明、晋升说明 | 联创/合伙人/高手/粉丝/城市主理人/合作方 |
| **活动 / event_info + event_join + event_session** | 首页线下重磅、进行中活动、活动详情、报名与签到 | 活动列表、场次、报名状态、支付状态 |
| **知识库 / knowledge_category + knowledge_content** | 成长页话题 Wiki、金句、工具、宝库 | 分类、内容类型（文章/工具/案例/Wiki）、统计与精选 |
| **知识行为 / knowledge_comment + knowledge_action** | 评论、点赞、收藏、实修心得发布 | 点赞/收藏/分享、UGC 精选至 Wiki |
| **积分 / user_point_logs + point_product + point_redemption** | 积分明细、贡献值明细、积分商城 | 行为积分与贡献点分离，明细与兑换 |
| **邀请 / user_invite** | 我的邀请、邀请码、邀请海报、邀请列表 | 邀请关系、奖励状态 |
| **成长 / user_growth + user_profiles.growth_stage** | 成长地图、阶段进度、成长记录 | 阶段变更历史、当前阶段与下一阶段建议 |
| **通知公告 / notices + notifications** | 首页公告滚动、消息中心（系统通知/互动/话题更新） | 系统级公告与用户级通知 |
| **系统配置 / sys_config** | 注册告知、隐私政策、关于我们、联系我们 | 系统级杂项 |
| **反馈**（需求有、表待补） | 意见反馈入口、反馈列表与回复 | 疑惑/许愿/点赞、处理状态与回复 |

## 四、页面与功能清单（对齐原型与表设计）

### 4.1 顶部导航（全局）

- 左侧：10倍好小图标 + 点击回首页
- 右侧：搜索框（约 4 字宽），点击进入**全局搜索**（活动、会议、宝库、话题、用户能力/资源等，基于标签与权限）

### 4.2 底部 Tab

| Tab | 页面路径 | 说明 |
|-----|----------|------|
| 发现 | pages/cust/home | 首页：公告滚动、线下重磅、进行中活动、知识库入口 |
| 成长 | pages/cust/growth | 学习中心：实修看板、话题 Wiki、金句库、探索资源（标签） |
| 连接 | pages/cust/publish | 中间加号：发布话题/实修心得，关联主题后提交 |
| 消息 | pages/cust/msg | 消息中心：系统通知、互动回复、话题更新 |
| 我的 | pages/cust/me | 头像/昵称/身份、贡献值/积分/成长日、成长地图、邀请、收藏、反馈、设置 |

### 4.3 列表与详情页（与表对应）

- **活动/课程**：列表来源于 `event_info`（biz_status 等），详情展示场次、价格、大纲、报名按钮；报名写入 `event_join`，支付状态、签到与 `event_session` / `event_check_in` 关联。
- **公告详情**：数据来自 `notices`（title、content、type、is_urgent、publish_time）。
- **话题/Wiki 详情**：数据来自 `knowledge_content` + `knowledge_category`，关联工具、共创案例；评论用 `knowledge_comment`，点赞/收藏用 `knowledge_action`。
- **工具详情**：`knowledge_content` 中 content_type 为工具类型，展示简介、使用指南、实操案例。
- **积分/贡献值明细**：`user_point_logs` / `user_contrib_logs`，按用户、时间查询。
- **邀请/关系网络**：`user_invite`，邀请码、海报、邀请列表（贡献值/积分/成长日等）。
- **成长地图**：`user_growth` 历史 + `user_profiles.growth_stage`，阶段说明与下一阶段建议。
- **全局搜索**：对接活动、知识内容、标签等检索接口（权限范围内）。

### 4.4 发布与互动

- **发布话题/实修心得**：关联主题（活动/场次/宝库/会议），富文本内容，可附图；提交后走审核/黑名单关键字（需求说明），发布成功后可打「新话题」标签；与 `knowledge_content` 或话题表（若单独建表）对应。
- **评论、点赞、收藏**：与 `knowledge_comment`、`knowledge_action` 一致。

## 五、MVP 与迭代（与需求优先级一致）

- **MVP（第一期）**：首页导航与公告、焦点区与活动流、我的在学看板、工具库、话题/活动详情（含报名）、个人资料与身份、金句/认知库与我的收藏（可为 P1）、意见反馈。**仅做 P0，确保一个核心线下课程的展示→报名→服务→沉淀闭环。**
- **V2**：积分体系、知识网络（话题 Wiki）、成长地图与身份、邀请有礼、我的打卡/心得、互动与系统通知、轻量数据看板、打卡功能。
- **V3+**：订阅消息、AI 能力等。

## 六、技术实现要点

- **技术栈**：UniApp + Vue3 + uview-plus，对接 tao-end 的 REST API 与 JWT。
- **数据**：列表/详情接口与 `changelog-2-business` 表一致（event_info、event_join、knowledge_*、notices、user_point_logs、user_contrib_logs、user_invite、user_profiles 等）。
- **权限**：按身份（identities）控制可见活动与知识库；未实现接口前可用 mock 数据保证页面与交互跑通。

## 七、页面文件与路由约定

- C 端用户入口页面统一放在 **tao-app/src/pages/cust/**。
- 路由 path：`pages/cust/home`、`pages/cust/growth`、`pages/cust/msg`、`pages/cust/me`、`pages/cust/publish`，以及 `pages/cust/event-detail`、`pages/cust/topic-detail`、`pages/cust/tool-detail`、`pages/cust/notice-detail`、`pages/cust/invite`、`pages/cust/level-guide`、`pages/cust/point-log`、`pages/cust/search` 等。
- TabBar 配置：发现、成长、连接（发布）、消息、我的 对应上述五个主页。
