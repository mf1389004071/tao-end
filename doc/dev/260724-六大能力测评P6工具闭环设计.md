# 六大能力测评（P6）与知识工具闭环 — 设计说明

> 日期：2026-07-24  
> 状态：已落地（MVP 闭环）  
> 依据：共创会方案 + 实施基线（biz_product / usage / action 双靶 / Power6Handler）

## 1. 目标闭环

配置产品与工具 → H5 直达测评（basic 免费）→ 高级 AI 解读（有效期免扣 / 过期扣 `available_points`）→ 小鹅通购买 → PC 登单 → 用户单号+手机兑换 → 授/延期身份 + 分润 → 私有评论分享（COMMENT+VIEW）→ 新用户邀请加次。

## 2. AI 引擎（yunwu / OpenAI 兼容）

项目原先 **无可用 LLM 客户端**（仅 `ai_tasks` CRUD）。现已最小落地：

| 组件 | 路径 |
| --- | --- |
| 配置 | `geek.ai.*`（`application-dev.yml`） |
| Client | `com.geek.ai.client.OpenAiCompatibleClient` |
| Facade | `com.geek.ai.service.AiChatService` |
| 默认网关 | **yunwu.ai**（`POST {base-url}/chat/completions`） |

环境变量：`YUNWU_API_KEY`（必填）、`YUNWU_BASE_URL`（默认 `https://yunwu.ai/v1`）、`YUNWU_MODEL`。

高级解读：`POST /bt10/cust/tool/unlock-pro`（`usageId` + 可选 `templateKey`）。成功写 `result_pro` + `ai_tasks`；非会员成功后再扣身份域次数。已有 `result_pro` 直接回看；进行中任务幂等返回 `RUNNING`。

### 本地 HTML 模板（多套可随机）

Classpath：`tool-templates/{toolCode}/*.html`（打进 jar）

- `tool-templates/POWER6/default.html`
- `tool-templates/POWER6/focus.html`

占位符：`{{subjectName}}` `{{scoresHtml}}` `{{aiNarrative}}` `{{aiActions}}` `{{focusDimension}}` `{{generatedAt}}`  
未传 `templateKey` 时 `ToolProTemplateService.pickRandomKey` 随机选套；响应含渲染后 `html`。

## 3. 关键表

| 表 | 说明 |
| --- | --- |
| `biz_product` | 现金/技能包产品（非积分商城） |
| `product_beneficiary` | 产品多方分润配置 |
| `knowledge_usage_record` | 知识使用真相（TOOL 为一种） |
| `knowledge_action` | 扩展双靶 CONTENT/COMMENT |
| `identities` / `user_identities` | P6 默认次数 / 实例 `available_points`+有效期 |
| `user_point_logs` / `user_invite` | 增 `identity_code`（身份域流水不进总积分） |

## 4. 工具处理器

`KnowledgeToolHandler` + `Power6ToolHandler`（toolCode=`POWER6`）：服务端计分与 `result_basic` 为真相。

## 5. C 端 API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/bt10/cust/tool/entitlement` | 权益（次数/有效期） |
| POST | `/bt10/cust/tool/submit` | 提交测评（落 usage + 私有评论） |
| POST | `/bt10/cust/tool/unlock-pro` | 高级 AI 解读 |
| POST | `/bt10/cust/tool/claim` | 小鹅通单号+手机兑换授期 |
| POST | `/bt10/cust/knowledge/view` | 工具打开 CONTENT VIEW（计热度） |
| POST | `/bt10/cust/knowledge/comment/view` | 分享打开 COMMENT VIEW（不计内容热度，回传结果） |
| POST | `/bt10/cust/invite/bind` | 新用户绑定邀请人（邀请人身份域 +1） |

### 微信授权（需你补配置，不在 SQL 内）

编辑 [`application-auth.yml`](../../geek-admin/src/main/resources/application-auth.yml)：

```yaml
oauth:
  wx:
    miniapp:
      appId: <小程序AppID>
      appSecret: <小程序AppSecret>
    pub:
      appId: <公众号AppID>      # H5 网页授权时用
      appSecret: <公众号AppSecret>
```

AI：`application-dev.yml` 的 `geek.ai` 或环境变量 `YUNWU_API_KEY`。
