# 将子模块并入 tao-end 主仓（以 Geek-Module-Generator 为例）

**说明**：geek-modules / geek-plugins / geek-scenes 下**已存在的模块**均已按相同思路解除与原 gitee 子模块的关联（删除 `.git/config` 中的 submodule 配置、删除 `.git/modules` 下对应元数据、在 `geek-modules.yml` 中注释对应条目），仅 Generator 曾为 gitlink 需额外执行 `git rm --cached` + `git add`，其余在仓库中已是普通目录。

## 背景

- `geek.sh` 通过 `geek-modules.yml` 将部分模块以 **git submodule** 形式拉取（如 Geek-Module-Generator）。
- 子模块在父仓库中只记录为一个 **gitlink**（mode 160000），即一个 commit ID，**不跟踪子模块内单个文件**。
- 因此在 tao-end 根目录执行 `git status` / `git diff` 时，看不到 Geek-Module-Generator 内部的文件改动；只有进入子模块目录或对「子模块指针」提交后，父仓才有变化。

若希望将某个模块**完全并入 tao-end**，提交到 tao-end 远程分支，并**不再**与原子模块远程（如 gitee.com/geek-xd/geek-module-generator）关联，可按下述步骤操作。

## 操作步骤（已对 Geek-Module-Generator 执行）

以下在 **tao-end 仓库根目录** 执行。

### 1. 从索引移除子模块（保留工作区文件）

```bash
git rm --cached geek-modules/Geek-Module-Generator
```

- 会从 Git 索引中删除「子模块指针」，**不会**删除磁盘上的 `geek-modules/Geek-Module-Generator` 目录及其中文件。

### 2. 删除子模块元数据

```bash
rm -rf .git/modules/geek-modules/Geek-Module-Generator
```

### 3. 从 .git/config 移除该子模块配置

编辑 `tao-end/.git/config`，删除如下整段（三行）：

```ini
[submodule "geek-modules/Geek-Module-Generator"]
	url = https://gitee.com/geek-xd/geek-module-generator.git
	active = true
```

- 若存在 `.gitmodules` 文件且其中有该 path，也一并删除对应条目。

### 4. 将目录作为普通文件加入主仓

```bash
git add geek-modules/Geek-Module-Generator
```

- 此后该目录下所有文件均按普通文件被 tao-end 跟踪，`git diff` / `git status` 可正常看到文件级差异。

### 5. 避免 geek.sh 再次将其当子模块

在 `geek-modules.yml` 中注释或删除 Geek-Module-Generator 的条目，避免执行 `./geek.sh sync-all` 时再次按子模块拉取覆盖。

### 6. 提交并推送到 tao-end 远程

```bash
git add geek-modules.yml   # 若修改了该文件
git commit -m "chore: 将 Geek-Module-Generator 并入主仓，不再作为子模块"
git push origin dev
```

## 为何之前看不到文件差异？

- 子模块在父仓库中对应的是 **一个 commit 引用**（gitlink），不是若干普通文件。
- 父仓的 `git diff` 只比较「当前工作区/暂存区」与「当前提交」；子模块目录在父仓视角下只是「一个对象」，其内部文件不属于父仓的跟踪集合，因此不会显示这些文件的改动。
- 转为普通目录并 `git add` 后，这些文件纳入 tao-end 的跟踪，差异即可正常显示。

## 其他模块

若要对其他 `geek-modules.yml` 中的模块做同样处理，重复上述步骤，将路径与名称替换为对应模块即可。注意：`geek.sh remove <name>` 会 **删除工作区目录**，若需保留本地改动，应先备份或按本文用手动步骤（仅 `git rm --cached` + 删元数据 + `git add`），不要用 `remove` 删目录。
