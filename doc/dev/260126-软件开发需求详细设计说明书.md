## 1. 项目概述与架构设计

### 1.1 项目定位

Better10 是一个基于"宏大单体(Majestic Monolith)"架构的AI原生数字化平台,致力于实现"10倍好"的交付效率与运维体验。平台融合道家智慧,通过**成长导航、知识共生、价值连接**三大核心能力,助力用户生命绽放。

**核心愿景**: 让十亿人智用道德经智慧生活  
**核心使命**: 每个生命绽放十倍好  
**核心价值观**: 成为管道,极致利他

### 1.2 技术架构

#### 1.2.1 后端架构

- **框架**: Laravel 11 (PHP 8.3)
- **数据库**: PostgreSQL 16
  - 扩展: `pgvector` (向量存储), `pg_trgm` (模糊匹配)
  - 优化: Session和Cache表配置为`UNLOGGED`表
- **AI服务**: 混合AI模型路由
  - 主力模型: DeepSeek V3/R1 (性价比优先)
  - 高端能力: OpenAI GPT-4o (多模态处理)
  - 合规兜底: 阿里通义千问 (中文处理)

#### 1.2.2 前端架构

- **管理端**: Vue 3 + Vite + Element Plus + TypeScript（前后端分离 SPA，参考 [catch-admin-vue](https://github.com/JaguarJack/catch-admin-vue)；包管理推荐 **pnpm**）
- **小程序端**: uni-app + Vue 3 + uView Pro + TypeScript

#### 1.2.3 源码目录结构规范(AI-Native)

## 2. 数据库设计说明

### 2.1 设计原则

1. **UUID主键**: 所有表使用UUID v7作为主键,便于分布式和AI编码
2. **软删除**: 所有业务表支持软删除,保留审计字段
3. **变更日志**: 重要业务数据(用户、活动、积分等)都有对应的变更日志表
4. **扩展字段**: 每张表都有`text1/text2/text3`和`json_data`扩展字段,便于未来扩展
5. **索引优化**: 为常用查询字段建立索引,JSONB字段使用GIN索引

### 2.2 核心表关系

```
users (用户)
├── user_point_logs (积分流水)
├── user_contribution_logs (贡献点流水)
├── user_invitations (邀请关系)
├── user_growth_records (成长记录)
└── user_change_logs (变更日志)

events (活动)
├── event_roles (活动角色)
├── event_registrations (报名)
│   ├── event_registration_roles (报名角色关联)
│   └── event_check_ins (签到记录)
├── event_sessions (活动场次)
└── event_change_logs (变更日志)

knowledge_contents (知识内容)
├── knowledge_comments (评论)
├── knowledge_likes (点赞)
├── knowledge_collections (收藏)
└── knowledge_categories (分类)

ai_tasks (AI任务)
├── ai_vectors (向量知识库)
└── meeting_transcripts (会议转写)
```

### 2.3 变更日志设计

所有重要业务数据的变更都记录在对应的变更日志表中,包含:
- **变更字段**: 具体哪个字段被修改
- **旧值/新值**: 变更前后的值
- **变更原因**: 为什么变更
- **操作人**: 谁操作的(用户ID、操作类型、IP地址)
- **变更时间**: 精确到毫秒

## 3. OneID统一身份系统

### 3.1 业务场景

#### 场景1: 新用户注册(溪水模型-感知阶段)

**用户目标**: 快速注册,获得首次价值体验

**前端流程**:
1. 用户打开小程序,看到价值触点流(精选内容、活动、高手)
2. 点击"立即加入"或"微信授权登录"
3. 如果是微信授权:
   - 调用`wx.login()`获取code
   - 调用后端API `POST /api/v1/auth/wechat/login`
4. 如果是手机号注册:
   - 输入手机号,获取验证码
   - 输入验证码和密码
   - 调用后端API `POST /api/v1/auth/register`
   - 可选: 输入邀请码

**后端实现**:

```php
// app/Actions/Auth/WechatLoginAction.php
class WechatLoginAction
{
    public function handle(WechatLoginDto $data): array
    {
        // 1. 通过code获取openid和unionid
        $wechatUser = $this->wechatService->getUserByCode($data->code);
        
        // 2. 查找或创建用户
        $user = User::where('wechat_unionid', $wechatUser['unionid'])
            ->orWhere('miniapp_openid', $wechatUser['openid'])
            ->first();
            
        if (!$user) {
            // 创建新用户
            $user = User::create([
                'wechat_unionid' => $wechatUser['unionid'],
                'miniapp_openid' => $wechatUser['openid'],
                'name' => $wechatUser['nickname'],
                'avatar_url' => $wechatUser['avatar'],
                'status' => UserStatus::PENDING,
                'role' => UserRole::MEMBER,
            ]);
            
            // 记录变更日志
            UserChangeLog::create([
                'user_id' => $user->id,
                'change_field' => 'CREATE',
                'new_value' => 'USER_CREATED',
                'operator_type' => 'SYSTEM',
            ]);
            
            // 触发新手任务
            event(new NewUserRegistered($user));
        }
        
        // 3. 生成JWT Token
        $token = auth()->login($user);
        
        // 4. 返回用户信息和token
        return [
            'user' => new UserResource($user),
            'token' => $token,
        ];
    }
}
```

**UI/UX要点**:
- 登录页面采用渐变背景,体现"溪水"流动感
- 微信授权按钮使用微信绿色,突出显示
- 手机号注册表单采用卡片式设计,输入框有清晰的占位符
- 邀请码输入框可选,有"我有邀请码"的展开动画

#### 场景2: 邀请注册(溪水模型-融入阶段)

**用户目标**: 邀请好友加入,获得积分奖励

**前端流程**:
1. 用户在个人中心点击"邀请好友"
2. 系统生成专属邀请码和邀请海报
3. 用户分享海报或链接

**后端实现**:

```php
// app/Actions/User/GenerateInvitationAction.php
class GenerateInvitationAction
{
    public function handle(User $user): array
    {
        // 1. 生成或获取邀请码
        if (!$user->invitation_code) {
            $user->invitation_code = $this->generateUniqueCode();
            $user->save();
        }

        return [
            'invitation_code' => $user->invitation_code,
            'invite_url' => $inviteUrl,
            'poster_url' => $posterUrl,
            'reward_points' => 50, // 邀请奖励积分
        ];

// app/Actions/User/ProcessInvitationAction.php
class ProcessInvitationAction
{
    public function handle(User $newUser, string $invitationCode): void
    {
        // 1. 查找邀请人
        $inviter = User::where('invitation_code', $invitationCode)->first();
        if (!$inviter) {
            return;
        }
        
        // 2. 建立邀请关系
        UserInvitation::create([
            'user_id' => $newUser->id,
            'inviter_id' => $inviter->id,
            'invitation_code' => $invitationCode,
            'status' => 'ACCEPTED',
        ]);
        
        // 3. 更新新用户的邀请人
        $newUser->inviter_id = $inviter->id;
        $newUser->save();
        
        // 4. 发放邀请奖励(给邀请人)
        $this->rewardInviter($inviter, $newUser);
        
        // 5. 发放新人奖励(给被邀请人)
        $this->rewardNewUser($newUser);
    }
    
    private function rewardInviter(User $inviter, User $newUser): void
    {
        // 增加积分
        $inviter->increment('points', 50);
        $inviter->increment('total_points', 50);
        
        // 记录积分流水
        UserPointLog::create([
            'user_id' => $inviter->id,
            'action_type' => 'INVITE_USER',
            'points' => 50,
            'balance_before' => $inviter->points - 50,
            'balance_after' => $inviter->points,
            'description' => "邀请用户 {$newUser->name} 注册",
            'related_type' => 'USER',
            'related_id' => $newUser->id,
        ]);

            'user_id' => $inviter->id,
            'change_type' => 'EARN',
            'points_change' => 50,
            'balance_before' => $inviter->points - 50,
            'balance_after' => $inviter->points,
            'change_reason' => '邀请用户注册奖励',
            'related_type' => 'USER',
            'related_id' => $newUser->id,
            'operator_type' => 'SYSTEM',
        ]);
    }
}
```

### 4.2 积分获取规则

#### 场景: 用户发布优质内容获得积分

**前端流程**:
1. 用户在知识库页面点击"发布心得"
2. 填写内容表单(标题、内容、关联话题、标签)
3. 选择公开程度(所有人可见/仅关注者/匿名)
4. 提交表单,调用API `POST /api/v1/knowledge/contents`

**后端实现**:

```php
// app/Actions/Knowledge/CreateContentAction.php
class CreateContentAction
{
    public function handle(CreateContentDto $data, User $user): KnowledgeContent
    {
        DB::beginTransaction();
        try {
            // 1. 创建内容
            $content = KnowledgeContent::create([
                'title' => $data->title,
                'content' => $data->content,
                'author_id' => $user->id,
                'category_id' => $data->category_id,
                'status' => ContentStatus::DRAFT,
                'tags' => implode(',', $data->tags ?? []),
            ]);
            
            // 2. 如果内容质量高,自动发布并奖励积分
            $qualityScore = $this->calculateQualityScore($content);
            if ($qualityScore >= 80) {
                $content->status = ContentStatus::PUBLISHED;
                $content->publish_at = now();
                $content->save();
                
                // 奖励积分(20-50分,根据质量)
                $points = $this->calculatePoints($qualityScore);
                $this->rewardPoints($user, $points, 'PUBLISH_CONTENT', $content);
            }
            
            // 3. 记录变更日志
            DataChangeLog::create([
                'table_name' => 'knowledge_contents',
                'record_id' => $content->id,
                'change_type' => 'CREATE',
                'operator_id' => $user->id,
                'operator_type' => 'USER',
            ]);
            
            DB::commit();
            return $content;
        } catch (\Exception $e) {
            DB::rollBack();
            throw $e;
        }
    }
    
    private function rewardPoints(User $user, int $points, string $actionType, $related): void
    {
        // 更新用户积分
        $balanceBefore = $user->points;
        $user->increment('points', $points);
        $user->increment('total_points', $points);
        $balanceAfter = $user->points;
        
        // 记录积分流水
        UserPointLog::create([
            'user_id' => $user->id,
            'action_type' => $actionType,
            'points' => $points,
            'balance_before' => $balanceBefore,
            'balance_after' => $balanceAfter,
            'description' => "发布优质内容奖励",
            'related_type' => get_class($related),
            'related_id' => $related->id,
            'expired_at' => now()->addYear(), // 1年后过期
        ]);
        
        // 记录变更日志
        PointChangeLog::create([
            'user_id' => $user->id,
            'change_type' => 'EARN',
            'points_change' => $points,
            'balance_before' => $balanceBefore,
            'balance_after' => $balanceAfter,
            'change_reason' => '发布优质内容',
            'related_type' => get_class($related),
            'related_id' => $related->id,
            'operator_type' => 'SYSTEM',
        ]);
    }
}
```

**UI/UX要点**:
- 内容编辑器支持Markdown,实时预览
- 标签输入支持自动补全,显示已有标签
- 发布按钮显示预计获得积分范围
- 发布成功后显示积分获得动画

### 4.3 积分消耗规则

#### 场景: 用户兑换课程优惠券

**前端流程**:
1. 用户在积分商城浏览商品
2. 点击"课程优惠券",查看详情
3. 确认兑换,调用API `POST /api/v1/points/redeem/{productId}`

**后端实现**:

```php
// app/Actions/Points/RedeemProductAction.php
class RedeemProductAction
{
    public function handle(PointProduct $product, User $user): PointRedemption
    {
        DB::beginTransaction();
        try {
            // 1. 检查积分是否足够
            if ($user->points < $product->points_required) {
                throw new InsufficientPointsException('积分不足');
            }
            
            // 2. 检查库存
            if ($product->stock_quantity >= 0 && $product->sold_quantity >= $product->stock_quantity) {
                throw new OutOfStockException('商品已售罄');
            }
            
            // 3. 扣除积分
            $balanceBefore = $user->points;
            $user->decrement('points', $product->points_required);
            $balanceAfter = $user->points;
            
            // 4. 创建兑换记录
            $redemption = PointRedemption::create([
                'user_id' => $user->id,
                'product_id' => $product->id,
                'points_used' => $product->points_required,
                'status' => 'COMPLETED',
                'redemption_code' => $this->generateRedemptionCode(),
                'expired_at' => now()->addDays($product->valid_days),
            ]);
            
            // 5. 更新商品销量
            $product->increment('sold_quantity');
            
            // 6. 记录积分流水
            UserPointLog::create([
                'user_id' => $user->id,
                'action_type' => 'REDEEM_PRODUCT',
                'points' => -$product->points_required,
                'balance_before' => $balanceBefore,
                'balance_after' => $balanceAfter,
                'description' => "兑换商品: {$product->name}",
                'related_type' => 'PointProduct',
                'related_id' => $product->id,
            ]);
            
            // 7. 记录变更日志
            PointChangeLog::create([
                'user_id' => $user->id,
                'change_type' => 'SPEND',
                'points_change' => -$product->points_required,
                'balance_before' => $balanceBefore,

                   (embedding <=> ?::vector) as distance

            ORDER BY distance
            LIMIT 10
        ", [json_encode($queryVector)]);

// app/Actions/Event/RegisterEventAction.php
class RegisterEventAction
{
    public function handle(Event $event, RegisterEventDto $data, User $user): EventRegistration
    {
        DB::beginTransaction();
        try {
            // 1. 检查活动状态和容量
            if ($event->status !== EventStatus::REGISTERING) {
                throw new EventNotAvailableException('活动不在报名中');
            }
            
            // 乐观锁检查
            $event->lockForUpdate();
            if ($event->registered_count >= $event->max_participants) {
                throw new EventFullException('活动已满员');
            }
            
            // 2. 检查是否已报名
            $existingRegistration = EventRegistration::where('event_id', $event->id)
                ->where('user_id', $user->id)
                ->first();
            if ($existingRegistration) {
                throw new AlreadyRegisteredException('您已报名此活动');
            }
            
            // 3. 计算支付金额
            $payment = $this->calculatePayment($event, $data->payment_method, $user);
            
            // 4. 创建报名记录
            $registration = EventRegistration::create([
                'event_id' => $event->id,

                'payment_amount' => $payment['total'],
                'payment_method' => $data->payment_method,
            ]);
            
            // 5. 处理支付
            $this->processPayment($registration, $payment, $user);
            
            // 6. 更新活动报名人数
            $event->increment('registered_count');
            $event->increment('version'); // 乐观锁版本号
            
            // 7. 分配角色(如果有)
            if ($data->role_id) {
                EventRegistrationRole::create([
                    'registration_id' => $registration->id,
                    'role_id' => $data->role_id,
                    'status' => 'ASSIGNED',
                ]);
            }
            
            // 8. 记录变更日志
            EventChangeLog::create([
                'event_id' => $event->id,
                'change_field' => 'REGISTRATION',
                'new_value' => "用户 {$user->name} 报名",
                'operator_id' => $user->id,
                'operator_type' => 'USER',
            ]);
            
            DB::commit();
            return $registration;
        } catch (\Exception $e) {
            DB::rollBack();
            throw $e;

    private function calculatePayment(Event $event, string $method, User $user): array
    {
        $coursePrice = $event->course_price;
        
        switch ($method) {
            case 'full_contribution':
                // 全贡献点支付
                return [
                    'total' => $coursePrice,
                    'contribution_amount' => $coursePrice,
                    'points_amount' => 0,
                    'cash_amount' => 0,
                ];
                
            case 'mixed_50':
                // 50%现金+50%积分
                $cashAmount = $coursePrice * 0.5;
                $pointsAmount = (int)($coursePrice * 0.5); // 1积分=1元
                return [
                    'total' => $coursePrice,
                    'contribution_amount' => 0,
                    'points_amount' => $pointsAmount,
                    'cash_amount' => $cashAmount,
                ];
                
            case 'points_only':
                // 全积分支付
                return [
                    'total' => $coursePrice,
                    'contribution_amount' => 0,
                    'points_amount' => (int)$coursePrice,
                    'cash_amount' => 0,
                ];
                
            default:
                throw new InvalidPaymentMethodException('无效的支付方式');
        }
    }
    
    private function processPayment(EventRegistration $registration, array $payment, User $user): void
    {
        // 1. 扣除贡献点
        if ($payment['contribution_amount'] > 0) {
            if ($user->contribution_points < $payment['contribution_amount']) {
                throw new InsufficientContributionException('贡献点不足');
            }
            
            $user->decrement('contribution_points', $payment['contribution_amount']);
            
            // 记录贡献点流水
            UserContributionLog::create([
                'user_id' => $user->id,
                'action_type' => 'PURCHASE',
                'amount' => -$payment['contribution_amount'],
                'balance_before' => $user->contribution_points + $payment['contribution_amount'],
                'balance_after' => $user->contribution_points,
                'description' => "报名活动: {$registration->event->title}",
                'related_type' => 'EventRegistration',
                'related_id' => $registration->id,
            ]);
        }
        
        // 2. 扣除积分
        if ($payment['points_amount'] > 0) {
            if ($user->points < $payment['points_amount']) {
                throw new InsufficientPointsException('积分不足');
            }
            
            $user->decrement('points', $payment['points_amount']);
            
            // 记录积分流水
            UserPointLog::create([
                'user_id' => $user->id,
                'action_type' => 'PURCHASE',
                'points' => -$payment['points_amount'],
                'balance_before' => $user->points + $payment['points_amount'],
                'balance_after' => $user->points,
                'description' => "报名活动: {$registration->event->title}",
                'related_type' => 'EventRegistration',
                'related_id' => $registration->id,
            ]);
        }
        
        // 3. 创建支付订单(如果需要现金支付)
        if ($payment['cash_amount'] > 0) {
            $paymentOrder = Payment::create([
                'order_no' => $this->generateOrderNo(),
                'user_id' => $user->id,
                'order_type' => 'EVENT',
                'related_type' => 'EventRegistration',
                'related_id' => $registration->id,
                'total_amount' => $payment['cash_amount'],
                'payment_status' => PaymentStatus::PENDING,
            ]);
            
            // 调用第三方支付接口
            $paymentResult = $this->paymentService->createOrder($paymentOrder);
            
            $registration->payment_id = $paymentResult['payment_id'];
            $registration->save();
        } else {
            // 无需现金支付,直接完成
            $registration->payment_status = PaymentStatus::PAID;
            $registration->paid_at = now();
            $registration->save();
        }
    }
}

{

    {

        $file = File::find($task->related_id);
        
        // 调用腾讯云ASR接口
        $result = $this->tencentAsrService->transcribe($file->path);
        
        // 记录费用
        $task->cost_amount += $result['cost'];
        $task->tokens_used += $result['tokens'];
        
        return $result['transcript'];
    }
    
    private function summarize(string $text): array
    {
        $prompt = "你是10倍好体系的知识官,请总结以下会议内容:\n\n{$text}\n\n请提供:\n1. 核心摘要(200字以内)\n2. 关键点(3-5条)\n3. 行动清单(如有)";
        
        // 调用AI模型(优先使用DeepSeek)
        $response = $this->aiService->chat([
            'model' => 'deepseek-chat',
            'messages' => [
                ['role' => 'system', 'content' => '你是一个专业的知识管理助手'],
                ['role' => 'user', 'content' => $prompt],
            ],
        ]);
        
        // 解析响应
        return $this->parseSummary($response['content']);
    }
    
    private function vectorize(MeetingTranscript $transcript): void
    {
        // 1. 文本切片(每500字一段)
        $chunks = $this->chunkText($transcript->full_text, 500);
        
        foreach ($chunks as $chunk) {
            // 2. 生成向量
            $embedding = $this->aiService->embed($chunk);
            
            // 3. 存储向量
            AiVector::create([
                'content_chunk' => $chunk,
                'embedding' => json_encode($embedding),
                'metadata' => [
                    'source_type' => 'MEETING',
                    'source_id' => $transcript->id,
                    'event_id' => $transcript->event_id,
                    'created_at' => $transcript->created_at,
                ],
            ]);
        }
    }
}
```

class PointsRankingService

CREATE OR REPLACE FUNCTION log_user_changes()
RETURNS TRIGGER AS $$
BEGIN
    IF TG_OP = 'UPDATE' THEN
        -- 记录每个字段的变更
        IF OLD.role IS DISTINCT FROM NEW.role THEN
            INSERT INTO user_change_logs (user_id, change_field, old_value, new_value, operator_id, changed_at)
            VALUES (NEW.id, 'ROLE', OLD.role::text, NEW.role::text, NEW.updated_by, NOW());
        END IF;
        
        IF OLD.status IS DISTINCT FROM NEW.status THEN
            INSERT INTO user_change_logs (user_id, change_field, old_value, new_value, operator_id, changed_at)
            VALUES (NEW.id, 'STATUS', OLD.status::text, NEW.status::text, NEW.updated_by, NOW());
        END IF;
        
        IF OLD.points IS DISTINCT FROM NEW.points THEN
            INSERT INTO point_change_logs (user_id, change_type, points_change, balance_before, balance_after, operator_id, changed_at)
            VALUES (NEW.id, 'ADJUST', NEW.points - OLD.points, OLD.points, NEW.points, NEW.updated_by, NOW());
        END IF;
    END IF;
    
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER user_changes_trigger
AFTER UPDATE ON users
FOR EACH ROW
EXECUTE FUNCTION log_user_changes();
