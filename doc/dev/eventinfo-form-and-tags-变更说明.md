# 活动信息表单与标签类型变更说明

## 1. tao-pc 活动信息表单（eventinfo）

### 1.1 表单布局与控件

- **布局**：新增/编辑对话框改为 **三列**（el-row + el-col :span="8"），对话框宽度 960px。
- **活动标题**：必填，单行输入，最大 100 字。
- **参与方式**：必填，枚举下拉（线上/线下/混合），单选。
- **活动分类**：必填，**字典下拉**，字典类型 **「活动分类」**，支持搜索（filterable）。字典类型与四条数据（近期热门、精选、进阶课、成长课）由 **Liquibase** 在 `changelog-2-dict-event-category.xml` 中初始化，重启应用即生效。
- **开始时间 / 结束时间 / 报名截止时间**：必填，日期选择，默认当天。
- **最大参与人数 / 已报名人数 / 已签到人数**：必填，整数输入框（el-input-number），默认 0。
- **乐观锁版本号**：已从表单中移除，不展示。
- **地点简述 / 详细地址**：文本域。
- **会议/直播链接**：普通输入框。
- **城市**：省市区级联（el-cascader），使用 **element-china-area-data**（regionData）。存储为单字段 **city**：逗号分隔的区域码字符串（如 `110000,110100,110101`），列表展示时用 `codeToText` 转成「省 / 市 / 区」文案。若后端需拆分为多字段（如 province_code、city_code、district_code 或省/市/区名称），可在表 `event_info` 上追加字段并在前端提交时分别赋值。
- **封面图 / 列表图**：单图上传（ImageUpload limit=1），提示为**鼠标悬停显示**、不占行高，预览卡片 **80×80** 像素。
- **详情图 / 海报图**：多图上传（ImageUpload limit=9），同上（悬停提示、80×80）。
- **参与奖励积分**：必填，整数，默认 0。
- **RRule周期规则**：普通输入框。
- **父活动ID(周期活动)**：选填，当前表（eventinfo）列表远程搜索下拉。
- **活动价格**：必填，双精度金额（el-input-number precision=2），默认 0。
- **活动类型**：必填，枚举下拉（工作坊/课程/见面会/直播/其他等）。
- **目标学员画像 / 活动标签**：标签选择器，选项来自 **tags 表**，按标签类型过滤：`EVENT_TARGET_AUDIENCE`、`EVENT_TAG`。存储为逗号分隔的标签 ID 字符串。
- **学习目标 / 转化策略 / 跟进计划 / 风险管理**：文本域，选填。
- **主办方 / 联系方式**：普通输入框。
- **负责人**：必填，**人员下拉选择器**（全局组件 `UserSelect`，远程搜索用户）。
- **备注**：文本域，选填。
- **活动详情**：富文本编辑器（Editor），放在表单最后。

### 1.2 活动详情字段与后端

- **当前实现**：界面上的「活动详情」绑定富文本编辑器，**存储在后端 `event_info.text1`** 字段（扩展文本1）。无需改表即可使用。
- **后续可选**：若需独立「活动详情」字段，可在表 `event_info` 中新增 `event_detail`（TEXT），并在实体与前端中改为使用 `eventDetail`，届时前端会改为提交 `eventDetail` 而非 `text1`。

## 2. 标签类型（tags）按用途补齐

在 **tao-pc 标签管理页**（tags/index.vue）的标签类型枚举中已新增按用途的类型，便于活动等场景按类型过滤：

| 值 | 说明 |
|----|------|
| `EVENT_TARGET_AUDIENCE` | 目标学员画像（活动） |
| `EVENT_TAG` | 活动标签 |

活动信息表单中的「目标学员画像」「活动标签」会按上述类型从 tags 表拉取选项。

## 3. 字典与数据初始化

- **活动分类**：字典类型 `活动分类`、字典数据（近期热门、精选、进阶课、成长课）由 **Liquibase** 脚本 `geek-admin/src/main/resources/db/changelog/changelog-2-dict-event-category.xml` 在应用启动时执行插入（若已存在则跳过），无需在管理后台手工配置。

## 4. 列表页

- 表格列较多时，列表区域使用 **横向滚动**（`.table-scroll-wrapper` + `el-table` 设置 `min-width`），超出屏幕可左右滚动查看。
